B

B
🛡️ Cybersecurity

🔨 Brute Force Attack

Kahulugan sa Filipino: Paraan ng pagpasok sa isang account o device sa pamamagitan ng sistematikong paghula sa napakaraming posibleng password hanggang sa tumama.

Simpleng Paliwanag: Parang pagsubok sa bawat kumbinasyon ng padlock hanggang bumukas. Mas madali itong magtagumpay kung maikli at madaling hulaan ang password, kaya inirerekomenda ang mahahaba at kakaibang password, at ang MFA bilang dagdag na harang.

Halimbawa o Application: Gumagamit ng programa ang hacker para subukan ang libu-libong password sa login page ng isang account, simula sa mga karaniwang password tulad ng “12345678”.

C
🌐 Computer Networking

🌐 Computer Networking

Kahulugan sa Filipino: Proseso ng pagkonekta ng dalawa o higit pang computer, device, o sistema upang makapagpalitan ng data at makapagbahagi ng resources tulad ng internet, files, at printers.

Simpleng Paliwanag: Sa maikling salita: pagkonekta ng mga computer at device para magbahagi ng impormasyon.

Halimbawa o Application: Ang mga computer sa computer laboratory ng paaralan na magkakakonekta sa iisang internet connection ay bahagi ng isang computer network.

C
🛡️ Cybersecurity

🛡️ Cybersecurity

Kahulugan sa Filipino: Pagprotekta sa mga computer, network, system, at data laban sa cyberattacks, hackers, malware, at iba pang banta sa internet.

Simpleng Paliwanag: Mga hakbang at teknolohiya upang mapanatiling ligtas ang impormasyon at mga computer system mula sa pagnanakaw, pagkasira, o hindi awtorisadong pag-access.

Halimbawa o Application: Paggamit ng antivirus, firewall, at malalakas na password upang maprotektahan ang computer laban sa hackers.

D

D
🌐 Computer Networking

📖 DNS (Domain Name System)

Kahulugan sa Filipino: “Phonebook ng internet” na nagsasalin ng mga pangalan ng website na madaling tandaan ng tao patungo sa mga numeric IP address na naiintindihan ng computer.

Simpleng Paliwanag: Kapag nag-type ka ng web address, sinusuri muna ng device ang lokal na cache; kung wala roon, magtatanong ito sa DNS resolver, at kung kailangan ay dadaan sa root at Top-Level Domain (TLD) servers hanggang makuha ang tamang IP address.

Halimbawa o Application: Nag-type ka ng google.com at isinalin ito ng DNS sa IP address tulad ng 142.250.190.46 upang ma-load ang pahina.

D
🛡️ Cybersecurity

🌊 DDoS (Distributed Denial-of-Service) Attack

Kahulugan sa Filipino: Sinadyang pag-atake na pinapabagsak ang isang server, serbisyo, o network sa pamamagitan ng pagbaha ng napakaraming trapiko sa Internet.

Simpleng Paliwanag: Parang biglaang matinding traffic na humaharang sa mga lehitimong sasakyan. Nag-i-infect ang attacker ng maraming device gamit ang malware para makontrol ito nang malayuan; bawat nakontrol na device ay bot, at ang grupo ng mga bot ay botnet. Sabay-sabay silang magpapadala ng request sa target, kaya hindi na makapasok ang totoong mga user.

Halimbawa o Application: Biglang hindi ma-open ang website ng enrollment ng paaralan sa araw ng enrollment dahil binabaha ito ng pekeng request mula sa libu-libong nakontrol na device.

E

E
🛡️ Cybersecurity

👁️ Endpoint Detection and Response (EDR)

Kahulugan sa Filipino: Proseso ng pagsubaybay, pagkolekta ng datos, at pagtuklas ng mga kahina-hinalang aktibidad o banta sa seguridad sa mga indibidwal na device na kumokonekta sa network.

Simpleng Paliwanag: Sa Tagalog: pagtuklas ng mga banta o kahina-hinalang kilos sa mga endpoint device — mga kagamitang konektado sa network.

Halimbawa o Application: Binabantayan ang isang laptop, desktop, server, o smartphone para matukoy ang kahina-hinalang aktibidad bago ito lumala.

E
🛡️ Cybersecurity

🔐 Encryption

Kahulugan sa Filipino: Proseso ng pag-convert ng readable data (plaintext) patungo sa naka-code o mukhang magulong format (ciphertext) gamit ang mathematical algorithm at security key.

Simpleng Paliwanag: Hindi mababasa ng magnanakaw o hacker ang sensitibong mensahe habang naglalakbay ito sa internet. Pagdating sa tatanggap, gagamitin ang tamang key para ibalik ito sa orihinal nitong anyo (decryption).

Halimbawa o Application: Naka-encrypt ang mensahe mo kaya kahit ma-intercept ito, hindi ito maiintindihan nang walang tamang key.

E
🌐 Computer Networking

🔌 Ethernet

Kahulugan sa Filipino: Tradisyunal na teknolohiya para sa pagkonekta ng mga wired local area network (LAN) na gumagamit ng mga physical cable.

Simpleng Paliwanag: Ito ang nakasanayang kable (tinatawag ding LAN cable) na direktang isinasaksak mula sa router patungo sa computer para magkaroon ng mas mabilis at mas matatag na internet kumpara sa Wi-Fi.

Halimbawa o Application: Pagsasaksak ng Ethernet cable (tulad ng Cat6) mula sa Wi-Fi router patungo sa likod ng isang gaming PC o desktop para maiwasan ang lag habang naglalaro o nag-a-upload ng malalaking files.

F

F
🛡️ Cybersecurity

🧱 Firewall

Kahulugan sa Filipino: Security system (maaaring hardware o software) na nagsisilbing harang o bantay sa pagitan ng pribadong network at ng pampublikong internet.

Simpleng Paliwanag: Taga-suri ng traffic: sinusuri nito ang lahat ng papasok at lumalabas na data packets batay sa itinakdang security rules. Tagapagtanggol: hinaharang nito ang kahina-hinalang koneksyon, hacker, o malware bago pa sila makapasok sa device o server.

Halimbawa o Application: Hinaharang ng firewall ang kahina-hinalang koneksyon bago ito makapasok sa iyong computer o LAN.

G

G
🌐 Computer Networking

🚪 Gateway (Default Gateway)

Kahulugan sa Filipino: Networking node o device na nagsisilbing daanan o tulay para makakonekta ang mga device sa isang lokal na network patungo sa ibang network o sa pampublikong internet.

Simpleng Paliwanag: Kung ang lokal na network ay isang saradong subdivision, ang gateway ay ang mismong main gate o exit papunta sa labas ng komunidad. Kung wala ito, hindi makalalabas ng lokal na network ang iyong computer para mag-browse sa internet.

Halimbawa o Application: Ang router sa inyong bahay ang nagsisilbing default gateway ng iyong laptop para makarating ang iyong mga request sa mga website sa internet.

H

H
🛡️ Cybersecurity

🔒 HTTPS (Hypertext Transfer Protocol Secure)

Kahulugan sa Filipino: Ligtas na bersyon ng HTTP na nag-e-encrypt ng datos sa pagitan ng browser at ng website.

Simpleng Paliwanag: Sa HTTP, plain text ang datos kaya mababasa ito ng sinumang nakikinig sa network, tulad ng sa pampublikong Wi-Fi. Sa HTTPS, naka-encrypt ito gamit ang TLS (dating SSL), kaya mukhang gulo ang makukuha ng magnanakaw. Gumagamit ang HTTPS ng port 443, samantalang port 80 ang HTTP. Hindi ito hiwalay na protocol — HTTP ito na tumatakbo sa ibabaw ng TLS.

Halimbawa o Application: Ang padlock icon sa address bar kapag nag-log in ka sa online banking. Senyales ito na naka-encrypt ang koneksyon.

I

I
🛡️ Cybersecurity

🚨 Intrusion Detection System (IDS)

Kahulugan sa Filipino: Proseso ng pagsubaybay sa mga pangyayaring nagaganap sa isang computer system o network at pagsusuri sa mga ito para sa mga palatandaan ng posibleng insidente.

Simpleng Paliwanag: Kabilang sa insidente ang paglabag o napipintong banta ng paglabag sa computer security policies, acceptable use policies, o standard security practices.

Halimbawa o Application: Para itong alarm system na nagbababala kapag may posibleng security threat sa network.

I
🌐 Computer Networking

🏠 IP Address

Kahulugan sa Filipino: Natatanging numerong tagapagkakilanlan na ibinibigay sa bawat device na konektado sa computer network na gumagamit ng Internet Protocol para sa komunikasyon.

Simpleng Paliwanag: Parang home address ng isang computer o cellphone kapag nakakonekta ito sa isang network o internet. Ito ang ginagamit upang makilala at maipadala ang tamang impormasyon sa isang device. May private IP (hal. 192.168.1.1–192.168.1.4) na ibinibigay ng lokal na router, at public IP (hal. 82.129.80.111) na ibinibigay ng ISP.

Halimbawa o Application: Kapag nakakonekta ang cellphone mo sa Wi-Fi, mayroon itong IP address na ginagamit upang makipag-ugnayan sa ibang devices at sa internet.

L

L
🌐 Computer Networking

🏫 LAN (Local Area Network)

Kahulugan sa Filipino: Koleksyon ng mga computer at device na magkakasamang konektado sa loob ng isang limitadong pisikal na lugar — tulad ng bahay, gusali ng opisina, o paaralan.

Simpleng Paliwanag: Nagbibigay-daan ito sa mga device na magbahagi ng datos, files, at hardware resources tulad ng printer. Ang mga device ay maaaring naka-wire gamit ang LAN/Ethernet cable o nakakonekta sa pamamagitan ng lokal na Wi-Fi, at pinamamahalaan ng switch o router ang panloob na trapiko.

Halimbawa o Application: Mga computer sa isang paaralan o opisina na magkakasamang nakakonekta at nagbabahagi ng iisang internet connection at printer.

M

M
🛡️ Cybersecurity

🐛 Malware

Kahulugan sa Filipino: Anumang programang idinisenyo upang makapanakit, magnakaw ng impormasyon, o makasira sa computer, smartphone, o network.

Simpleng Paliwanag: Maikling tawag sa malicious software. Iba-iba ang kilos nito: virus na kumakabit sa lehitimong programa at kumakalat; ransomware na nag-e-encrypt ng files at humihingi ng ransom; spyware na lihim na nangongolekta ng personal na impormasyon, passwords, o browsing habits; at Trojan na nagpapanggap na kapaki-pakinabang na application pero may nakatagong mapaminsalang code.

Halimbawa o Application: Isang pekeng application na mukhang kapaki-pakinabang pero lihim na nagnanakaw ng impormasyon.

M
🛡️ Cybersecurity

🔑 Multi-Factor Authentication (MFA)

Kahulugan sa Filipino: Paraan ng pagpapatunay ng pagkakakilanlan na nangangailangan ng dalawa o higit pang magkakaibang authentication factors bago makapasok sa isang account o system.

Simpleng Paliwanag: Bukod sa password, kailangan mo pang magbigay ng karagdagang verification upang mapatunayan na ikaw ang tunay na may-ari ng account.

Halimbawa o Application: Kapag nag-log in ka sa iyong email, kailangan mong ilagay ang password at mag-enter ng verification code na ipinadala sa iyong cellphone.

N

N
🌐 Computer Networking

🔄 Network Address Translation (NAT)

Kahulugan sa Filipino: Teknolohiya na nagpapalit ng IP address ng mga device habang dumadaan ang kanilang data sa isang router.

Simpleng Paliwanag: Pinapayagan nito ang maraming devices na gumamit ng iisang public IP address upang makakonekta sa internet.

Halimbawa o Application: Ang mga cellphone, laptop, at computer sa bahay ay maaaring gumamit ng iisang public IP address sa pamamagitan ng router.

P

P
🌐 Computer Networking

✉️ Packet (Data Packet)

Kahulugan sa Filipino: Maliit na piraso ng mas malaking mensahe o datos na ipinapadala sa network.

Simpleng Paliwanag: Hindi buo ang pagpapadala ng datos sa Internet. Hinahati ito sa maliliit na packet, at pinagsasama-sama ulit ng tatanggap na device. Parang pagpapadala ng malaking puzzle sa pamamagitan ng maraming sobre. Bawat packet ay may header (label na may pinanggalingan at patutunguhang IP address, laki, at iba pa) at payload (ang aktuwal na datos).

Halimbawa o Application: Kapag nag-send ka ng larawan sa Messenger, hinahati ito sa maraming packet. Pagdating sa cellphone ng kausap mo, pinagdudugtong ito pabalik bilang isang buong larawan.

P
🌐 Computer Networking

📉 Packet Loss

Kahulugan sa Filipino: Pagkabigo ng isa o higit pang mga data packet na makarating sa kanilang patutunguhan habang naglalakbay sa network.

Simpleng Paliwanag: Parang pagpapadala ng mga pahina ng isang libro sa pamamagitan ng koreo, tapos may ilang pahinang nawala sa daan kaya hindi mabasa nang buo ang kwento. Nagdudulot ito ng pagbagal, pagka-lag, o pagka-putol ng koneksyon.

Halimbawa o Application: Kapag nag-a-audio o video call ka tapos biglang naputol ang boses ng kausap mo o naging pixelated ang video, kadalasan ay dahil ito sa packet loss sa network.

P
🛡️ Cybersecurity

🎣 Phishing

Kahulugan sa Filipino: Uri ng cyberattack kung saan nagpapanggap ang isang masamang loob bilang pinagkakatiwalaang entidad o organisasyon upang linlangin ka na ibigay ang iyong sensitibong impormasyon.

Simpleng Paliwanag: Ang pain: nagpapadala ang attacker ng pekeng email, mensahe, o link na mukhang lehitimo. Ang patibong: ginagamit mo ang link para mapunta sa pekeng website na kamukha ng totoo. Ang pagnanakaw: kapag inilagay mo roon ang username, password, o credit card details, direktang mapupunta ito sa mga kamay ng hacker.

Halimbawa o Application: Pekeng email na kunwari galing sa bangko, na may link patungo sa pekeng login page.

P
🌐 Computer Networking

🕵️ Proxy Server

Kahulugan sa Filipino: Server na nagsisilbing tagapamagitan sa pagitan ng isang user at ng internet o iba pang network resources.

Simpleng Paliwanag: Tumatanggap at nagpapasa ito ng mga request ng user papunta sa kanilang kinakailangang website o server. Sa madaling salita, nagsisilbing tulay ito sa pagitan ng computer ng isang user at ng internet. Maaari rin itong gamitin upang kontrolin ang internet access, mag-filter ng mga website, at magtago ng direktang IP address ng user mula sa destination server.

Halimbawa o Application: Sa isang paaralan, maaaring gumamit ng proxy server upang limitahan ang pag-access ng mga estudyante sa mga website na hindi angkop sa oras ng klase, at kontrolin ng IT administrator kung anong mga website ang maaaring bisitahin.

R

R
🛡️ Cybersecurity

💰 Ransomware

Kahulugan sa Filipino: Uri ng malware na nag-e-encrypt o nagla-lock ng mga file sa computer ng biktima at humihingi ng kabayaran (ransom) kapalit ng susi para maibalik ito.

Simpleng Paliwanag: Parang pag-kidnap sa iyong mga importanteng dokumento o litrato sa computer. Haharangin nila ang iyong pag-access at magbabanta silang buburahin o hindi ibabalik ang mga ito hangga’t hindi ka nagbabayad ng pera.

Halimbawa o Application: Biglang na-lock ang screen ng computer ng isang kumpanya at may lumabas na mensahe na humihingi ng Bitcoin para maibalik ang kanilang database.

R
🌐 Computer Networking

📡 Router

Kahulugan sa Filipino: Networking device na nagdidirekta ng trapiko ng data sa pagitan ng iyong mga lokal na device at ng internet.

Simpleng Paliwanag: Nagbabahagi ito ng internet access mula sa modem patungo sa mga telepono, laptop, at smart device sa pamamagitan ng Wi-Fi o Ethernet cable; nagbibigay ng local/private IP address sa bawat konektadong device upang maipadala ang data sa tamang screen; at pinoprotektahan ang network gamit ang built-in firewall at encryption.

Halimbawa o Application: Kinukuha ng router ang koneksyon mula sa modem at ibinabahagi ito sa mga device sa bahay.

S

S
🛡️ Cybersecurity

📊 Security Information and Event Management (SIEM)

Kahulugan sa Filipino: Teknolohiya sa cybersecurity na tumutulong sa mga organisasyon na bantayan, suriin, at matukoy ang mga posibleng banta sa seguridad sa kanilang mga computer network at sistema nang real-time.

Simpleng Paliwanag: Sa Tagalog: Pamamahala ng Impormasyon at Kaganapan sa Seguridad. Ginagawa nito ang pagtitipon ng datos (log collection), pagsusuri (real-time analysis), at alerto (alerting) sa security team.

Halimbawa o Application: Kinokolekta ng SIEM ang mga ulat (logs) mula sa iba’t ibang aplikasyon, server, at network devices, sinusuri ang mga ito para sa kahina-hinalang galaw, at nagbibigay ng babala upang agad matugunan ang problema.

S
🌐 Computer Networking

📶 SSID (Service Set Identifier)

Kahulugan sa Filipino: Natatanging pangalan na ibinibigay sa isang wireless local area network (WLAN) o Wi-Fi network.

Simpleng Paliwanag: Ito ang pangalan ng Wi-Fi na nakikita mo sa listahan ng mga magagamit na koneksyon sa iyong cellphone o laptop kapag gusto mong kumonekta sa isang wireless network.

Halimbawa o Application: Kapag binuksan mo ang Wi-Fi setting ng iyong telepono at nakita mo ang mga pangalang tulad ng “PLDT_Home_Fibre_1234” o “Globe_At_Home”, iyon ang mga SSID.

S
🌐 Computer Networking

🔀 Switch

Kahulugan sa Filipino: Hardware device na nagkokonekta sa iba’t ibang device nang magkakasama sa isang iisang local area network (LAN) gamit ang mga Ethernet cable.

Simpleng Paliwanag: Hindi tulad ng mga lumang hub na nag-broadcast ng data sa bawat port, ang switch ay nagpapadala ng data nang direkta at partikular lamang sa eksaktong device na humiling nito, kaya nananatiling mabilis at ligtas ang trapiko sa network. Pinalalawak din nito ang bilang ng mga wired port na magagamit.

Halimbawa o Application: Pagsasaksak ng maraming computer, printer, at gaming console sa isang switch upang magkonekta sila sa iisang LAN.

V

V
🛡️ Cybersecurity

🕳️ VPN (Virtual Private Network)

Kahulugan sa Filipino: Teknolohiya na lumilikha ng ligtas at naka-encrypt na koneksyon sa pagitan ng iyong device at ng internet.

Simpleng Paliwanag: Kapag walang VPN, direktang dumadaan ang iyong data sa iyong Internet Service Provider (ISP) at nakikita nila ang iyong totoong IP address at mga binibisitang website. Kapag may VPN, dumadaan ang iyong data sa secure at naka-encrypt na “tunnel” papunta sa isang VPN server, na nagtatago ng iyong totoong IP address at pinapalitan ito ng IP address ng server.

Halimbawa o Application: Gumagamit ka ng VPN sa pampublikong Wi-Fi upang hindi mabasa ng ISP o ng mga hacker ang iyong mga ginagawa online.

Z

Z
🛡️ Cybersecurity

✅ Zero Trust Architecture (ZTA)

Kahulugan sa Filipino: Security framework na nangangailangan ng patuloy na beripikasyon bago payagan ang isang user o device na maka-access sa system.

Simpleng Paliwanag: Hindi agad nagtitiwala ang system sa isang user kahit nakakonekta na ito sa network. Kailangang mapatunayan muna ang pagkakakilanlan at pahintulot nito.

Halimbawa o Application: Kahit empleyado ka ng isang kumpanya, kailangan mo pa ring mag-authenticate bago ma-access ang confidential company files.
